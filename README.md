## 📖 Sobre o projeto

**dart-functions** é uma calculadora simples via terminal, feita em **Dart**, com o objetivo de praticar a criação e o uso de funções. O usuário digita dois números e o programa retorna o resultado da soma, subtração, multiplicação e divisão entre eles. Não é um projeto elaborado ou com pretensão de uso real — apenas um exercício rápido para fixar conceitos.

## 🛠️ Tecnologias

## ⚙️ Como executar

```bash
# Clone o repositório
git clone https://github.com/kevinhsdev/dart-functions.git

# Entre na pasta do projeto
cd dart-functions

# Instale as dependências
dart pub get

# Execute
dart run bin/coding.dart
```
